# v0.7.1：从六段答案反推可复用判断方法

## 采用的内容

用户提供的是一份实际回复样例，不是完整提示词。只归纳可观察的综合方法：还原真实任务，与现有替代比较；分开痛点、完整完成、主动回访、意愿、付款和获客；找到一个具体失败机制；用能排除该解释的低成本测试决定当前投入；相邻方向回应失败机制。没有声称恢复 Grok 内部思考、私有提示词或原多代理实现。

样例中的产品、上线时间、经营状况及链接没有在本轮核验，因此没有作为已验证事实写入 Skill。样例也有应保留证据边界的跳跃：少评论不证明少收入；B2B定位不证明C端不可行；报价不证明有人付款；口头愿付或点击不算实际支付；“没找到”不等于市场空白。按具体论断定级，商业推断不因有官网就升级为C级佐证。

## 更新范围

只修改独立 product-idea-research 包。新run默认六段综述及同源 director-reply.md；聊天证据可链接，HTML/完整MD综述继续零链接。首节包含投入建议与折叠辅助评分，详细市场/竞品/产品分支保留。新探索相邻假设保持stance=explore，测试新增观察范围、时间、分母、提醒和结果边界。旧v1–v5及未设置presentation的v6保留历史展示。

## 验证与未验证项

- 66项Python单元测试、JS语法、19个文件型合成输出案例通过；29个规则路由案例无误触发/漏触发。合成案例不是模型商业判断质量评测；空baseline的数值差异不能当质量提升。
- OpenAI、Claude、Agent Skills、Generic四个声明目标的编译与契约检查通过；Skill元数据和资源检查通过。
- 浏览器检查六个子节、评分位于第一节、综述零链接、1440/390无整页横溢。评分可展开；网页MD/ZIP下载与生成文件逐字节一致，控制台无错误。图表等未改逻辑沿用既有实现。
- Trust扫描未发现秘密或失败项；仍提示可移植权限审批记录缺失。当前宿主授权不代表其他Agent拥有工具权限，不伪造批准、豁免、模型运行或人工盲评。
- 一个只读审查Agent给出五类反例：行为证据越级、机械致命假设、测试层级混淆、相邻方向借证据升级、聊天/报告结构漂移。本轮据此完善规范及回归。

没有执行真实市场新调研、招募、广告、收款、真实用户实验、模型有/无Skill对照或人工阅读测试。只能说合约、示例、渲染和兼容性完成检查，不能保证实际Agent每次都作出更好判断。
