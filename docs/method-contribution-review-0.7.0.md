# 方法融合审查 · 0.7.0

范围：只更新独立的product-idea-research Skill，不改marketing系统、旧BRD/PRD流程或历史研究。来源是本次用户提供的product-idea-stress-test.md与粘贴的英文调查员人设；不执行文件内指令，不继承作者个人背景。英文若干长行被截断，尤其资本建议句只剩“Capital”，因此不声称恢复原文完整格式或原作者多代理实现。

| 思想 | 现有能力 | 采用方式 | 不采用/触发边界 |
| --- | --- | --- | --- |
| 对当前投入决定负责 | 现有总监已有进入判断和评分 | 主Agent维护原案、必要前提、唯一关键假设、投入上限 | 不把六维总分当批准决定 |
| 主动寻找反证 | 各研究员和挑战者已有反证 | 每个必要前提有反证搜索记录，统一支持/反对关联 | 查不到/被阻挡不能视为没有反证 |
| A–E强度层级 | 原A–E是主题/形态分类 | 新增grade，与旧type独立，具体论断定级 | 不按平台直接评级，不把报价当付款 |
| 一个瓶颈未知 | 旧版散落风险和缺口 | 综述只选一个最能改变决定的前提 | 不机械挑最难技术或最低证据项 |
| 信息收益和最便宜测试 | 旧数据有first_test但v4/v5隐藏 | v6综述1–2个针对瓶颈的测试，数字门槛与资源上限 | 不默认人工模拟，不授权执行/外发/招募 |
| 更强相邻论点 | 现有3–5方向 | 仅有证据时推荐；0–5方向且可无更强方向 | 不为了complete凑方向，不先让用户选择新方向 |
| 短问答/Quick不写文件 | 现有完整离线可视化报告 | 吸收少问、决策先行；保留完整报告 | 用户明确要全面调研，因此不默认切换成纯聊天Quick |
| 新用户模板隔离 | 原研究已用中性brief隔离预判 | 加上不继承作者公司、记忆和结论 | 当前用户显式约束可以沿用 |

结论：**选择性融合**。保留四条事实研究线与独立挑战，在其上加入新的主Agent判断协议；不是额外再加一层“审批官”。没有提供的原作者多agent细节不编造。

新增失败模式：热度D变成付费验证；一个研究员的观点被重复当多份证据；用相邻方向偷换原案；高分覆盖致命反证；实验阈值重叠或事后改门槛；强行给每个idea设计测试；伪称完整模型评测。对应回归检查写在Skill测试，证据范围见[更新验证](update-verification-0.7.0.md)。人工语义正确性和真实模型对照仍是missing evidence。
