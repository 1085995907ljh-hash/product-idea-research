# v0.7.0 更新与验证

## 行为变化

仅更新独立的 product-idea-research 包。产品 Idea 调查总监固定原案和 3–5 条必要前提，派原有隔离研究角色查支持与反对，再选一个会改变当前投入决定的关键假设。挑战者检查论点偷换、证据虚高和测试错位；最多两轮广泛研究，不无限扩搜。

第一章改为研究综述：结论、论点、前提、双向证据、关键假设、低成本测试、可选相邻方向、资源承诺及辅助评分。市场、竞品、产品研究保留深度。新 schema 为 v6，旧 v1–v5 继续历史契约。旧 evidence.type 不变，新 grade 独立表示论断强度。

## 边界

本轮未执行新的真实市场调研、真实用户测试、模型有/无 Skill 对照、人工盲评或阅读时长测试。空 baseline 产生的评估差值不能解释为模型质量提升。Yao 的通用可移植权限审批记录仍缺失，未伪造批准或豁免；当前本机任务授权不代表其他宿主已授予登录、付费库或工具权限。Skill 仍按宿主真实权限执行。

安装前核对两个本机安装目录均与旧版 Git 源码一致，无本地定制漂移；备份后同步。分发 ZIP 使用临时 Git index 收录新文件，不改变用户实际暂存区。未提交、推送或发布 GitHub。
